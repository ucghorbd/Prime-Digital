# Prime Digital Frontend

A responsive React + Vite frontend starter for a modern earning platform.

## Tech Stack
- React
- Vite
- React Router
- Firebase

## Folder Structure
- `src/components` → reusable UI sections
- `src/pages` → route pages
- `src/firebase` → Firebase setup
- `src/styles` → global styles

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
